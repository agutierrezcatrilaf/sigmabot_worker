Arquitectura general

SigmabotConfig (Angular) consume SigmabotConfig.Api (.NET 8), que lee/escribe SQL Server. SigmabotSync.Console corre en paralelo contra la misma BD, ejecuta trabajos programados y se comunica con Aconex (HTTPS) y shares SMB (lectura de archivos).

SigmabotConfig (Angular 19) → SigmabotConfig.Api (.NET 8) → SQL Server ↑ SigmabotSync.Console (.NET 8) ─────────┘ (misma BD) ↓ Aconex API (HTTPS) + shares SMB (lectura de archivos)

Consideración operativa

La consola no hace net use ni impersonación. Lee PathFisico con la identidad de la Tarea Programada. Para rutas UNC de dominio, configurar SERVICE_ACCOUNT en lugar de SYSTEM.
